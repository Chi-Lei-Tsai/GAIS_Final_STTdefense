# Archived Launch Scripts

These scripts are preserved to document earlier local runs:

- legacy diarized ASR;
- whole-audio timestamped ASR on local GPU;
- whole-audio timestamped ASR on strict CPU;
- diarization-routed Whisper-small/Whisper-large CPU ASR.

They are not the supported path for new experiments. Use
`eval/scripts/current/run_audiojailbreak_origin_whisper_large.ps1` for the
current cloud-GPU pipeline.
